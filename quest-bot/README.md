# 🗝️ Брони квестов — личный Telegram-бот с мини-приложением

Бот-блокнот для записи броней игр в квесте. Всё управление — в мини-приложении
внутри Telegram.

## Что умеет мини-приложение

- Добавить / изменить / удалить бронь: квест, дата, время, кол-во игроков,
  имя и телефон клиента (звонок в один тап), сумма, предоплата, статус, заметка.
- Вкладки «Предстоящие», «Сегодня», «Прошедшие», «Все», поиск по всем полям.
- Брони сгруппированы по дням; сверху итог: число игр, игроков и сумма.
- Подсказывает остаток к оплате («долг»), если предоплата меньше суммы.
- Статусы: 🕓 ожидает, ✅ подтверждена, 🏁 сыграна, ✖️ отменена.
- Цвета подстраиваются под тему Telegram (светлую/тёмную).

**Где хранятся данные:** в Telegram CloudStorage — облачном хранилище
Telegram для твоего аккаунта и этого бота. Сервер и база не нужны, записи
синхронизируются между телефоном и компьютером и видны только тебе.
Лимит — 1024 брони (можно удалять старые).

## Установка (один раз)

### 1. Выложить мини-приложение (GitHub Pages)

Мини-приложению нужен https-адрес. Проще всего — бесплатный GitHub Pages:

1. Влей эту ветку в `main`.
2. В репозитории: **Settings → Pages → Build and deployment → Source:
   GitHub Actions**.
3. Запусти workflow **Deploy quest webapp to GitHub Pages** (вкладка Actions)
   или просто запушь изменения в `quest-bot/webapp/`.
4. Адрес будет: `https://timursharafutdinov.github.io/TimurSharafutdinov/`

### 2. Запустить бота

```bash
cd quest-bot
cp .env.example .env
# впиши BOT_TOKEN и проверь WEBAPP_URL
python3 bot.py
```

Нужен только Python 3.8+, библиотеки не нужны. При запуске бот:
- ставит кнопку **«Брони»** слева от поля ввода (открывает приложение);
- регистрирует команды `/start` и `/id`.

Напиши боту `/id`, впиши полученное число в `OWNER_ID` в `.env` и перезапусти —
тогда бот будет отвечать только тебе.

> Кнопка «Брони» сохраняется в Telegram, поэтому **приложение работает, даже
> когда `bot.py` выключен**. Скрипт нужен, по сути, один раз — для настройки
> и ответа на `/start`. Держать его запущенным постоянно не обязательно.

### Альтернатива без GitHub Pages

В @BotFather: `/mybots → бот → Bot Settings → Configure Mini App` и укажи
любой https-адрес, где лежит `webapp/index.html` (Netlify, Vercel,
Cloudflare Pages и т.п.).

## Безопасность токена

Токен лежит только в `quest-bot/.env`, который исключён из git (`.gitignore`).
Никогда не коммить его. Если токен где-то засветился — в @BotFather:
`/mybots → бот → API Token → Revoke current token` и впиши новый в `.env`.

## Файлы

- `webapp/index.html` — мини-приложение (один файл, без сборки).
- `bot.py` — бот (long polling, только стандартная библиотека Python).
- `.env.example` — шаблон настроек.
